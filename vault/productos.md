# Catalogo de modulos - TechChip Systems S.A.

- **AI-Edge 1 (x1)**: modulo de bajo consumo para dispositivos edge.
- **AI-Server Pro (x2)**: modulo de alto rendimiento para servidores.
- **AI-Autonomous Car (x3)**: modulo especializado para vehiculos autonomos.
- **AI-IoT LowPower (x4)**: modulo de ultra bajo consumo para IoT.
- **AI-Robotics Heavy (x5)**: modulo de alta potencia para robotica industrial.
- **AI-Medical Vision (x6)**: modulo especializado en vision por computadora medica.

Cada modulo se produce por turno, en miles de unidades. La produccion de
cada modulo consume una combinacion distinta de los seis recursos de la
planta (ver recursos.md).
